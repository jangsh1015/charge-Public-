면책 및 사용 안내

  FT8CN은 FT8 신호를 어떻게 디코드하고 송신하는지 연구·학습할 목적으로 만든 앱입니다.
  이 앱을 쓰면서 생기는 결과에 대해서는 원작자와 한국어판 수정자가 책임지지 않습니다.

  대한민국에서 사용할 때는 전파법과 무선국 운용 규정을 지켜야 합니다.
  아마추어무선국 허가(호출부호) 없이 송신할 수 없고, 허용된 주파수와 출력, 운용 모드,
  호출부호 표시 같은 국내 규정을 반드시 확인하고 지키세요.
  수신만 하는 SWL은 무선국 허가 없이도 할 수 있습니다.

  휴대전화의 성능과 배터리 한계를 고려해 신호 처리는 가벼운 연산으로 하고 있으며,
  심층 디코드(deep decode) 같은 무거운 처리는 하지 않습니다.

  좋은 제안이나 문제가 있으면 앱의 [FAQ] 버튼으로 알려 주세요.

한국어판 변경 내역

  0.93-kr3
   1. 추적 자동 호출에서 무응답으로 중단된 국은 30분간 자동 재호출에서 제외합니다.
      (직접 콜사인을 눌러 부르거나 상대가 먼저 부르면 그대로 응답하고, 30분이 지나면 다시 부를 수 있습니다.)
   2. 앱을 처음 설치했을 때 기본 주파수를 40m(7.074 MHz)로 시작합니다.

  0.93-kr2
   1. [정보] 창을 한국어로 번역하고 원작·수정자 크레딧을 넣었습니다.
   2. 중국어로 보이던 무전기 모델 목록과 일부 오류 안내 문구를 한국어로 바꿨습니다.
   3. 간헐 CQ로 대기하는 동안에는 송신 감시(Tx watchdog) 시간을 세지 않아,
      대기 중에 자동 송신이 꺼지지 않습니다.
   4. 호출 탭의 확성기 아이콘을 송신 중(빨강 깜박임), 자동 송신 대기 중(주황),
      꺼짐(X)으로 구분해 보여 줍니다.

  0.93-kr1
   1. 화면과 도움말 전체를 한국어로 번역했습니다.
   2. 간헐 CQ(주기적 Auto CQ) 기능을 추가했습니다.
      설정의 [간헐 CQ]에서 주기와 1회 송신 횟수를 정할 수 있습니다.
