면책 및 사용 안내

  FT8CN은 FT8 신호를 어떻게 디코드하고 송신하는지 연구·학습할 목적으로 만든 앱입니다.
  이 앱을 쓰면서 생기는 결과에 대해서는 원작자와 한국어판 수정자가 책임지지 않습니다.

  대한민국에서 사용할 때는 전파법과 무선국 운용 규정을 지켜야 합니다.
  아마추어무선국 허가(호출부호) 없이 송신할 수 없고, 허용된 주파수와 출력, 운용 모드,
  호출부호 표시 같은 국내 규정을 반드시 확인하고 지키세요.
  수신만 하는 SWL은 무선국 허가 없이도 할 수 있습니다.

  휴대전화의 성능과 배터리 한계를 고려해 신호 처리는 가벼운 연산으로 하고 있으며,
  심층 디코드(deep decode) 같은 무거운 처리는 하지 않습니다.

  좋은 제안이나 문제가 있으면 앱의 [FAQ] 버튼으로 알려 주세요.

한국어판 변경 내역

  0.93-kr6
   1. 태블릿 가로에서 '디코드' 탭을 열면 디코드 목록을 왼쪽·오른쪽 2열로 보여 줍니다.
      한 화면에 두 배로 많은 국이 들어오고, 3분할 패널 안의 좁은 목록은 1열 그대로입니다.
   2. 태블릿 가로에서 '호출' 탭을 누르면 왼쪽에 호출 창, 오른쪽에 QSO 로그가 나란히 열립니다.
      가운데 경계선을 끌어 좌우 폭을 바꿀 수 있고(30~70%), 그 비율은 앱을 다시 켜도 유지됩니다.
   3. 디코드 목록에서 국을 눌러 호출 화면으로 넘어갈 때도 같은 2분할이 그대로 열립니다.
   4. 마지막에 보던 화면(디코드 단독 / 호출+로그 / 스펙트럼 3분할·단독)으로 다시 시작합니다.
      [QSO 로그] 탭과 [설정] 탭은 지금처럼 전체 화면이고, 스펙트럼 탭은 3분할입니다.
   5. QSO 로그의 제목 막대 색을 디코드·호출 목록과 같은 어두운 인디고 톤으로 맞췄습니다.

  0.93-kr5
   1. 같은 상대에게 같은 내용의 메시지를 끝없이 되풀이하지 않습니다.
      '무응답 N회 중단'(기본 3회)만큼 같은 메시지를 보내면, 신호 리포트(R-11 같은)를
      보내는 중이어도 자동 호출을 멈추고 CQ/대기로 돌아갑니다.
      상대가 이미 RR73·RRR·73으로 교신을 끝냈으면 리포트를 더 보내지 않고
      73을 한 번만 보낸 뒤 CQ로 돌아갑니다.
   2. 교신 목록(디코드·호출) 색을 아이폰 FT8-Improved처럼 바꿨습니다.
      CQ=초록, 나를 호출한 수신=핑크, 내 송신(TX)=빨강, 그 밖의 교신=다크 네이비.
      밝은 파란 바탕 대신 어두운 바탕에 밝은 글씨를 써서 화면이 덜 부시고
      읽기는 더 또렷합니다. 열 제목 줄과 제목 막대도 어두운 인디고로 맞췄습니다.
   3. 워터폴 위에서 일렁이던 세로 막대그래프를 없애고, 눈금선 바로 아래부터
      워터폴이 화면 아래까지 꽉 차게 했습니다.
   4. 전체화면·주파수·볼륨·지구본 도구 버튼이 태블릿 가로 3분할에서는
      오른쪽 목록을 가리지 않고 왼쪽 워터폴 아래 구석으로 옮겨 갑니다.
   5. 태블릿 가로에서 하단 탭으로 화면을 고를 수 있습니다.
      [스펙트럼] 탭은 3분할(스펙트럼+디코드+호출)로 열리고, 한 번 더 누르면 스펙트럼만 전체로 접힙니다.
      [디코드] 탭은 디코드 목록만, [호출] 탭은 호출 화면만 전체로 엽니다.
      마지막에 쓰던 화면(3분할/단독)은 앱을 다시 켜도 그대로 유지됩니다.
   6. 시각 동기화가 안 될 때 영어 오류 문장 대신 알아보기 쉬운 한국어로 알려 줍니다.
      (인터넷 연결이 없거나, 무전기 Wi-Fi에 연결된 동안에는 동기화되지 않습니다)

  0.93-kr4
   1. 태블릿을 가로로 두면 화면을 세 칸으로 나눠 씁니다.
      왼쪽에 스펙트럼·워터폴, 오른쪽 위에 디코드 목록, 오른쪽 아래에 호출 화면이 함께 뜹니다.
      칸 사이의 경계선(가운데 알약 모양 손잡이)을 끌어 크기를 바꿀 수 있고,
      바꾼 크기는 앱을 다시 켜도 그대로 유지됩니다. (스펙트럼 30~75%, 디코드 20~80%)
   2. 워터폴·스펙트럼 색감을 눈이 편하게 다듬었습니다.
      잡음 배경은 어두운 딥 네이비로 낮추고, 실제 신호는 청록 → 노랑 → 주황 → 빨강으로
      뚜렷하게 보이도록 바꿨습니다.
   3. IC-705 기준 초기 설정을 기본으로 넣었습니다.
      무전기 모델 ICOM IC-705(CI-V A4), 통신 속도 115200, SWR·ALC 경보 켜짐,
      무응답 3회면 자동 호출 중단. 처음 켜질 때 한 번만 적용되며, 그 뒤에 바꾼 값은 그대로 유지됩니다.

  0.93-kr3
   1. 추적 자동 호출에서 무응답으로 중단된 국은 30분간 자동 재호출에서 제외합니다.
      (직접 콜사인을 눌러 부르거나 상대가 먼저 부르면 그대로 응답하고, 30분이 지나면 다시 부를 수 있습니다.)
   2. 앱을 처음 설치했을 때 기본 주파수를 40m(7.074 MHz)로 시작합니다.
